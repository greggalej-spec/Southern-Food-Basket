# Risk register: Southern Food Basket concept site

S0 audit file 5 of 5. Written 2026-10-28 for PRD section 27.1 (`docs/prd/SFB-PRD-001.md:1156`). Branch `concept-v1`, HEAD `aa5a7f8`. Part A re-scores the 14 risks in PRD 26.1 (`SFB-PRD-001.md:1113-1128`) against this repo. Part B lists risks found in the code.

## 0. How to read this

- Severity scale: **Critical** = real personal data exposed or wrongly accessible. **High** = would put wrong information, a legal problem or a broken workflow in front of the public or staff. **Medium** = would cause rework or confusion. **Low** = tidy-up.
- Severity is for the case where this code, or a copy of its patterns, is used for the official site. Today the repo is an unofficial concept with demo data only (`data/seed.js:6`). Each row says so where it matters.
- Every row cites evidence as `path:line` or a command and its result. "Not assessed" means no evidence was gathered. This audit did not run a browser, a server, a build or a test (route-map.md and current-state.md section 1).
- Cross-references: `current-state.md` is the requirement-by-requirement table, `integrations.md` the PRD 18.4 table, `asset-inventory.md` the files and rights.
- Mitigation text is a suggestion for S1 planning. Nothing was changed in the repo.
